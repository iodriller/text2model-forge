# Roadmap

## Preview exit criteria

- Clean checkout installation passes on Windows, Ubuntu, and macOS core mode.
- Static-prop corpus produces valid textured GLBs for at least 8 of 10 prompts
  on each supported GPU configuration.
- Every published sample includes timings, peak VRAM, hashes, backend revisions,
  review decisions, and license lineage.
- No globally blocked model can enter a globally cleared release package.
- Release archives and containers include checksums, an SBOM, and build
  provenance.

## 0.2 — Auditable static props

- Finish and publish the ten-prompt static-prop corpus.
- Add browser GLB inspection and downloadable evidence bundles.
- Qualify one globally usable geometry and surface combination.
- Validate GLB independently of any game engine; keep Unity optional.

## 0.3 — Rigged bipeds

- Qualify a learned rigging worker on at least twenty varied meshes.
- Measure landmark validity, weight normalization, deformation, equipment
  attachment, contact, and runtime import.
- Replace functional stress clips with properly licensed production motion.

## 0.4 — Engine adapters

- Keep glTF validation as the portable baseline.
- Add optional, isolated Unity and Godot validation adapters.
- Consider Unreal only after its automation and licensing boundary are clear.

## Non-goals

- Training a new foundation model.
- Claiming generated output is automatically production-ready.
- Hosting Studio as an unauthenticated public service.
- Hiding model or territory restrictions behind a convenience installer.
